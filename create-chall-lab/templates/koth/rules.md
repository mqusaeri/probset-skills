# Aturan main KOTH

Dikirim ke tim sebelum mulai.

- Tujuan: tulis nama tim kamu di `/root/king.txt` dan pertahanin selama mungkin.
- Skor dihitung tiap GANTI_INI menit. Tim yang namanya ada di king.txt saat itu dapet poin.
- Boleh: nambal celah, ganti password, nutup jalan masuk kamu sendiri.
- Nggak boleh: matiin atau blok king reader di port 9999 atau service di port 8080, ngubah
  king.txt jadi isi selain nama tim, hapus king.txt, DoS ke box, tim lain, atau platform.
- Melanggar aturan: box di-reset dan poin tim bisa dikurangi.
- Kalau box rusak bukan karena tim, kabari panitia, box di-reset.
